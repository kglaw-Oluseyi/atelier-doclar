# Protected stop conditions

- Claude planning artifacts absent/unratified

- Actual repository contradicts assumed stack or paths

- Provider/hosting/auth choice unresolved

- Baseline not reproducible

- Migration destructive or rollback/containment absent

- Status could be manually marked accepted without evidence

- RAG could retrieve unauthorised/superseded content or answer without
  citation

- External or CEO approval would be inferred

- Security, accessibility or audit weakened
