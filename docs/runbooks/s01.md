# Local setup

1. Install pnpm 9.15.4 and Node 20.19.
2. Create a database named `eos_s01_dev`.
3. Export `DATABASE_URL`, `EVENT_OS_SESSION_SECRET` of at least 32 characters, and `EVENT_OS_ALLOW_FIXTURES=1`.
4. Run `pnpm install --frozen-lockfile`.
5. Run `pnpm migrate`.
6. Run `pnpm --filter @maison-doclar/event-os dev`.

The migration creates schema `eos_s01` only.

# Rollback

If the Event OS deployment cannot be restored, roll Railway deployment `6bd04814-19f8-4ec3-b625-31c558fbfe5f` back onto the Event OS service. Do not roll back Control Tower, solver-worker or Postgres. Do not rewrite Git history.

# Migrations

`pnpm migrate` applies `001_foundation` and records its checksum. A second run must not report drift. There is no destructive down migration. Repair is forward-fix.
