# Explainability and redaction

Every seated guest receives exactly one verified short reason. Empty / invented / unproven “Best preference match” reasons are forbidden. Explanation failure ⇒ `SOLVER_FAULT(EXPLANATION_INVALID)` and blocks adoption.

Canonical short reasons: Locked to this seat; Locked to this table; Reserved placement; Only permitted table; Moved for mandatory rule; Existing seat retained; Seated with required group; Separated by mandatory rule; Moved to fit changes; Preference met; Equal options · stable choice; Placed by whole-plan optimisation.

Ordinary-role redaction; no counterpart-name leakage; per-event discretion mode; authorised expandable detail; rate-limited “Why not Table X?” counterfactuals.
