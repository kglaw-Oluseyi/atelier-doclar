# Authority and network laws

1. Cloud Event OS is authoritative during planning and after certified reconciliation.
2. A signed event package is the released baseline.
3. One fenced edge server is the event-day write authority while the cell is active.
4. Clients submit commands; they do not merge shared truth.
5. Core, external-services, management and venue/guest networks are routed security zones with default-deny policy.
6. Venue internet, cloud and FaceGate loss cannot stop declared core workflows.
7. FaceGate cannot create initial attendance, admit, deny or directly mutate attendance.
8. Every consequential mutation is atomic with immutable ledger and reconciliation outbox records.
9. Ambiguous reconciliation is quarantined; last-write-wins is prohibited for consequential domains.
10. Human welfare, safety and authorised judgment override automation.
