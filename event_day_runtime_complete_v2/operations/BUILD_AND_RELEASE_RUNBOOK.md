# Build and release runbook

1. Ratify controlled documents and unresolved authority decisions.
2. Run Cursor prompt R0; establish repository baseline and gap register.
3. Execute R1–R18 sequentially, accepting one coherent commit at a time.
4. Run R19–R21 to build evidence, deployment and operational runbooks.
5. Run R22 full acceptance in a synthetic laboratory environment.
6. Run R23 evidence collation only; it cannot sign external approvals.
7. Perform venue survey, dress rehearsal, shadow event and controlled pilot.
8. Independent assessor records acceptance or blockers.
9. CEO authorises a stated event tier, build, configuration and policy set.
